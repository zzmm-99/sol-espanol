# SOL · 西语日常

一个面向中文母语者的西班牙语日常交流学习网站：从一句 `Hola` 开始，通过 16 个真实生活场景，练习能在日常对话中用出来的西语。

## 功能

- 16 个情景课，8 周 A0 → A2 核心路线
- 129 句本地西班牙语对话音频，5 个情景实战
- 单词卡、随身短语、发音实验室、语法锦囊
- 断点续学、个人中心、学习进度、全局设置
- 深色导航轨道、Bento 首页、全站毛玻璃卡片

## 本地打开

直接双击 `index.html` 即可，无需安装或构建。

也可以在当前目录启动本地服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 说明

学习记录保存在浏览器 `localStorage`，不会上传。课程对话音频为本地 MP3；跟读评分需要麦克风、联网，并建议使用 Edge / Chrome。
